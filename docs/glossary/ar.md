# معجم المصطلحات الرسمي ودليل التعريب: العربية (ar)

**النمط اللغوي:** اللغة العربية الفصحى المعاصرة (أسلوب راقٍ، واضح، تأملي وإيجابي).
**الاتجاه:** من اليمين إلى اليسار (`dir="rtl"`).
**الجمهور المستهدف:** الناطقون باللغة العربية حول العالم.

## 3. قواعد الروابط والأرقام وتصميم RTL

1. **عناوين الروابط (Slugs):**
   - اعتماد العناوين اللاتينية المنقولة صوتياً (Transliterated Latin Slugs) مثل:
     - `/ar/matrix-al-qadar`
     - `/ar/khat-al-hub`
     - `/ar/khat-al-maal`
     - `/ar/al-thayl-al-karmi`
     - `/ar/hasiba`
   - هذا يحفظ التوافقية العالية مع محركات البحث وبروتوكولات الروابط.

2. **هندسة مخطط مصفوفة القدر (SVG):**
   - **تنبيه هام:** لا يتم عكس (Mirror) الرسم الهندسي للنجمة الثمانية بأي شكل.
   - النقاط (A، B، C، D، E) والاتجاهات الرمزية تبقى في موضعها الأصلي، بينما يتم تعريب النصوص والبطاقات والأوصاف المحيطة فقط.

3. **الأرقام وإدخال التواريخ:**
   - استخدام الأرقام الغربية القياسية (0–9) لمدخلات تاريخ الميلاد لتفادي أي ارتباك حسابي.
   - صيغة التاريخ: `DD/MM/YYYY`.

4. **تصدير PDF باللغة العربية:**
   - التعامل الدقيق مع تشبيك الحروف وتوجيه النص Bidirectional (Bidi).
   - إذا تعذر دعم المحاذاة في مكتبة jsPDF، يتم استخدام بديل توليدي موثوق أو توفير إشعار تفسيري أنيق.

5. **الإشعار القانوني:**
   - تتضمن الصفحات القانونية تنبيهاً صريحاً بأن النص الإنجليزي هو المرجع القانوني الملزم.
