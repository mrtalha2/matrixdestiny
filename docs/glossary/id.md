# Glosarium Resmi dan Panduan Lokalisasi: Bahasa Indonesia (id)

**Ragam Bahasa:** Bahasa Indonesia baku, alami, dan komunikatif (sapaan hangat dan santun 'Anda').
**Target Pembaca:** Pengguna penutur bahasa Indonesia di Indonesia dan diaspora.

## 3. Format Tanggal dan Angka
- Input tanggal lahir: `DD/MM/YYYY`
- Digit: Angka Arab Barat standar (0–9)
- Penafian Hukum: Dinyatakan secara lugas bahwa versi bahasa Inggris merupakan dokumen yang mengikat secara hukum.
